## Performance Optimization: Event loop and lock minimization
- In tight queuing code holding a thread lock, try to perform aggregations (like computing the length of items in a specific status with `sum(...)`) **once** rather than repeatedly in a `while` loop.
- Example: Refactoring a `while True:` loop that recalculates limits and grabs items one by one into a single `with lock:` block that computes `available_slots` once and collects a batch of jobs in a list to launch threads outside the lock reduces complexity from $O(N \times K)$ to $O(N)$ and decreases lock contention time, avoiding $100\%$ CPU spin scenarios.
